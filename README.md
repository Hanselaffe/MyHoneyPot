# MyHoneyPot — Maintained Legacy Sensor

This repository is the **legacy** honeypot prototype. The 2026 maintenance branch hardens that historical code without pretending it is the newer Honeypot-v2 project.

## 2026 safety refresh

- sensor bind defaults to `127.0.0.1:8080`;
- a non-loopback sensor address requires the explicit `--expose` flag;
- the Flask dashboard always binds to `127.0.0.1` with debug/reloader disabled;
- client reads are bounded to 1024 bytes by default and have a timeout;
- incoming bytes are never decoded or retained as raw payload content;
- events store source IP/port, byte count and SHA-256 only;
- event records use JSONL and UTC timestamps;
- the log is size-bounded with one simple rotation;
- dashboard output is limited to the latest 200 parsed events;
- historical live-socket test code is replaced with offline unit tests;
- generated bytecode is removed and ignored;
- Flask is updated to 3.1.3; unused Requests/Werkzeug pins are removed.

## Explicit external sensor binding

Example:

```bash
python run.py --sensor-host 0.0.0.0 --sensor-port 8080 --expose
```

`--expose` only confirms operator intent. It does **not** prove that firewall rules, VM isolation, routing or upstream network containment are safe. Review those controls separately before exposing a honeypot.

## Data minimization

The sensor does not retain received payload bytes. For each connection fragment it records only:

- UTC timestamp;
- source IP and port;
- received byte count;
- SHA-256 of the received bytes.

This supports basic event correlation without keeping potentially hostile or sensitive raw content.
